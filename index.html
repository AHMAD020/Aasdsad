Häufige Fragen

Antworten auf die wichtigsten Fragen rund um Shopify.

Brauche ich Programmierkenntnisse?

Nein. Shopify ist so gestaltet, dass du deinen Shop komplett ohne Code aufsetzen kannst. Für individuelle Anpassungen kannst du Liquid, HTML oder CSS nutzen.

Kann ich Shopify kostenlos testen?

Ja, es gibt eine kostenlose Testphase. Danach kannst du für den ersten Monat oft zu einem stark reduzierten Preis starten.

Welche Zahlungsmethoden werden unterstützt?

Shopify Payments, PayPal, Klarna, Apple Pay, Google Pay, Kreditkarten (Visa, Mastercard, Amex) und über 100 weitere.

Kann ich meine eigene Domain nutzen?

Ja. Du kannst eine bestehende Domain verbinden oder direkt über Shopify eine neue kaufen.

Gibt es einen deutschen Support?

Ja. Shopify bietet 24/7 Support auf Deutsch per Chat, E-Mail und Telefon sowie eine umfangreiche Wissensdatenbank.
