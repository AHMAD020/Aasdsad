# Shopify Guide

Eine moderne, responsive Landingpage über Shopify – die führende E-Commerce-Plattform.

## Inhalt

- **Hero-Sektion** mit Einführung und Shop-Vorschau
- **Funktionen** – 6 zentrale Vorteile von Shopify
- **Preise** – Übersicht der Shopify-Tarife
- **Anleitung** – 4 Schritte zum eigenen Shop
- **FAQ** – Antworten auf häufige Fragen
- **Call-to-Action** mit E-Mail-Formular

## Technologie

- Reines HTML5, CSS3 und JavaScript
- Keine externen Abhängigkeiten
- Vollständig responsiv (Mobile, Tablet, Desktop)
- Barrierefreie Semantik

## Lokal ausführen

Öffne einfach `index.html` in deinem Browser oder starte einen lokalen Server:

```bash
python3 -m http.server 8000
```

Anschließend im Browser aufrufen: [http://localhost:8000](http://localhost:8000)

## Dateien

- `index.html` – Struktur der Seite
- `styles.css` – Design und Layout
- `script.js` – Interaktionen (Formular, Animationen)

## Hinweis

Diese Seite ist ein unabhängiger Informations-Guide und steht in keiner offiziellen Verbindung zu Shopify Inc.
